# Система «Нейро-преподаватель»: Интеллектуальный помощник на базе RAG-системы

Это прототип десктопного приложения, созданный для помощи преподавателям в быстрой навигации и анализе учебных материалов. Проект решает проблему ручного поиска информации, используя современные технологии **NLP (Natural Language Processing)** и **LLM (Large Language Models)**.

---

### **Ключевые особенности**

* **Автоматизация поиска:** Система позволяет находить нужную информацию в документах (.docx/.pdf) за считанные секунды.
* **Гибкость:** Проект может быть адаптирован для работы с различными источниками данных.
* **Практическая польза:** Прототип показал потенциал **сокращения времени поиска информации на 20-30%** по сравнению с ручным методом.

---

### **Техническая реализация**

* **Язык программирования:** Python
* **Фреймворки и библиотеки:**
    * **Tkinter:** Для создания интуитивно понятного пользовательского интерфейса (UI).
    * **Langchain, Sentence Transformers:** Для обработки и анализа текста.
* **Архитектура:**
    * **RAG-система (Retrieval-Augmented Generation):** Основа проекта, которая объединяет поиск информации и генерацию ответов с помощью нейросети.
* **Работа с данными:**
    * **Yandex Cloud ML SDK:** Для взаимодействия с **LLM**.
    * **ChromaDB:** Векторная база данных для эффективного хранения и поиска.
